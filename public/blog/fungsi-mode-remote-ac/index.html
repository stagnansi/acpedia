Arti dan Fungsi Tombol Remote AC: Cool, Dry, Fan, dan Eco

Banyak kasus AC terasa “kurang dingin” bukan karena unit rusak, melainkan karena pengguna salah memilih mode operasional pada remote control.

Mode Operasional Utama:

  • Cool Mode (Simbol Butiran Salju): Mode pendinginan standar. Kompresor bekerja penuh mendinginkan ruangan sesuai target temperatur.
  • Dry Mode (Simbol Tetesan Air): Mode penurun kelembapan (dehumidifier). Blower berputar lambat agar uap air di udara menempel pada kisi evaporator dan dibuang keluar. Cocok dipakai saat cuaca lembap atau hujan.
  • Fan Mode (Simbol Kipas): Hanya memutar kipas indoor tanpa menyalakan kompresor outdoor. Berfungsi layaknya kipas angin biasa.
  • Auto Mode: Sistem otomatis menentukan mode kerja berdasarkan pembacaan suhu sensor ruangan.
  • Eco / Energy Saver Mode: Membatasi konsumsi daya listrik kompresor agar bekerja di kisaran watt yang lebih rendah.
